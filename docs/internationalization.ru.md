# Локализация (i18n)

Приложение поддерживает английский и русский UI. Имена и описания товаров локализуются через простую in‑memory карту.

## Культуры

- Поддерживаются UI‑культуры: `en`, `ru`
- Культура по умолчанию: `en` (числа — `en-US`)

## Переключение языка

- Query‑параметр: `?culture=en` или `?culture=ru`
- Cookie: POST на `/Localization/Set` с полями `culture` и `returnUrl`

## Локализация товаров

- `ProductCatalogLocalizer` подставляет имя/описание по RU для конкретных ID
- EN — значение по умолчанию (исходные тексты в `ProductRepository`)

## Ресурсы

- Включён каркас UI‑локализации с путём `Resources`; при необходимости добавляйте `.resx`
