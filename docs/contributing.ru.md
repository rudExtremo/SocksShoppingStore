# Вклад

Спасибо за интерес к улучшению SocksShoppingStore!

## Рекомендации

- Язык: комментарии к коду, коммиты и PR — на английском
- Стиль: кратко, единообразные имена, небольшие фокусные изменения
- Коммиты: Conventional Commits (например, `feat: add ru localization for products`)
- Тесты: добавляйте при изменении логики

## Разработка

- Запуск локально: `dotnet run --project SocksShoppingStore`
- Сохраняйте безопасные дефолты `appsettings.json` (лимиты, guard) для демо
- При добавлении переключателей предпочитайте конфигурацию константам

## Pull Request

- Опишите изменение, мотивацию и риски
- Укажите влияние на безопасность/производительность
- Для UI — добавьте скриншоты или краткие заметки
