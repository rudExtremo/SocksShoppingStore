# Опции хранения

Приложение поддерживает два провайдера репозитория товаров:

- Память (по умолчанию): обёртка над статическим списком, без записи на диск
- JSON‑файл: хранение товаров в JSON с автоинкрементом ID

## Настройка

В `SocksShoppingStore/appsettings.json`:

```
"Repository": {
  "Provider": "InMemory" | "Json",
  "Json": {
    "Path": "App_Data/products.json"
  }
}
```

- Относительные пути резолвятся от корня контента
- При первом запуске JSON‑репозиторий инициализируется из in‑memory списка

## DI

`Program.cs` регистрирует `IProductRepository` на основе конфигурации. Контроллеры используют интерфейс без изменений.
