# Обзор

SocksShoppingStore — небольшое, самодостаточное демо ASP.NET Core MVC, демонстрирующее:

- Просмотр каталога «профессия‑тематических» носков (поиск в шапке, компактные фильтры, ленивое дозагружение)
- Детальная карточка товара и добавление в корзину, хранимую в сессии
- Локализация EN/RU для UI и текстов товаров
- Производственные аспекты: CSP/защищённые заголовки, free‑tier guard, rate limiting, ограничение конкуренции и простые метрики

Проект умышленно простой: in‑memory репозиторий без базы данных.

## Ключевые возможности

- Корзина в сессии: товары сохраняются в пределах браузерной сессии
- Поиск в шапке: иконка лупы раскрывает компактную панель
- Фильтры: цена min–max, сортировка кнопками с иконками
- Ленивая загрузка: клиент подгружает следующую страницу через `/api/products` (вместо пагинации)
- API: `GET /api/products` (отдельный лимит)
- Health‑проверка: `GET /healthz` возвращает `OK`
- Операционные метрики: `GET /_status` (allowlist IP)
- Переключение языка: через cookie или query‑параметр (`?culture=en|ru`)

## Что входит в объём

- MVC‑контроллеры и Razor‑представления
- Middleware для security headers, free‑tier guard и ограничений конкуренции
- Ограничение скорости запросов (глобально + для API)
- Минимальная конфигурация через `appsettings.json`

## Что не входит

- Настоящий платёж/чекаут
- База данных или внешнее хранилище
- Аутентификация/авторизация сверх базовых безопасных настроек
