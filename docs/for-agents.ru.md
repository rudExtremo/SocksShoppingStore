# Для AI-агентов

Короткая памятка по входным точкам, лимитам и безопасным действиям.

## Точки входа

- Обзор каталога: `GET /` (HTML)
- Детали товара: `GET /Products/Details?id=<int>` (HTML)
- API товаров: `GET /api/products` (JSON)
- Health: `GET /healthz` (text `OK`)
- Метрики: `GET /_status` (JSON; allowlist IP)

## Лимиты и защиты

- Глобальный rate‑limit на IP (в минуту) и более строгая политика `api`
- In‑process лимит конкуренции (по умолчанию 10)
- Free‑tier guard может блокировать большинство путей (503) в зависимости от конфигурации
- Security headers и CSP; не используйте inline‑скрипты без nonce

## Поведение

- Локализация: контент зависит от `culture` (`en`/`ru`) из query или cookie
- Корзина живёт в сессии; нет межсессионной персистентности
- Аутентификация не требуется; не отправляйте чувствительные данные

## Стабильность

- Публичные маршруты и JSON‑схема стабильны для демо; изменения отражаются в `docs/` и релиз‑заметках
